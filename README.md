# 浙江大学外国语学院 · A/B/C 官网设计对比 Demo

## 最新字体与 B 版调整

- 三版固定院训使用用户选定的 P1 清秀行书（Xingkai SC Light）矢量路径，手机按四字词组排为两行；A/B 装饰底纹同样固定字形，C 的竖向毛笔底纹继续使用原图。
- 正文和标题使用同站点 WOFF2 字体：Campus Sans / Campus Serif，分别从 Adobe 思源黑体、思源宋体精简生成，许可证见 dist/assets/type。字体总计 409,084 字节，不依赖访客电脑安装字体或外部字体服务。
- 新增正文内容后需运行 scripts/build_typography.py 更新字体字符范围。当前页面全部汉字已检查覆盖；未覆盖的其他文字或未来新增字符仍可能使用回退字体。
- 仅 B 首页学术交流海报改为铺满宽度、从顶部裁切；隐藏卡片摘要，保留标题、主讲人、日期、地点和详情入口。A/C 及详情页不受该调整影响。
- 已检查桌面和 390px 浏览器布局；并非已在所有实际手机、浏览器和操作系统上测试。固定字形一致，屏幕抗锯齿和缩放仍可能带来细微视觉差别。

## 三个版本

- A 版：dist/index.html。粗体栏目标题，栏目名为“此刻外院”，适合强调清晰的信息层级。
- B 版：dist/editorial.html。大字黑红文案 + 小字栏目名称，适合对比人文气质。
- C 版：dist/calligraphy.html。在 B 版上，仅把装饰性院训改为竖向毛笔书法底纹，四组分别为语通世界、言载九州、文传未来、化成天下。石碑的原碑文字形保持独立。
- 两版除首页八处栏目标题及标题样式外，内容、图片、页面结构、导航、交互一致。
- 通知公告下方红色“学术讲座”按钮已删除；学术交流海报板块保持独立。

## 本地运行

在本目录执行：

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory dist
```

A 版：http://127.0.0.1:5173/
B 版：http://127.0.0.1:5173/editorial.html
C 版：http://127.0.0.1:5173/calligraphy.html

也可以直接打开上述两个 HTML 文件，无需安装依赖。

## 素材与事实边界

图片由用户提供，复制到 dist/assets，未覆盖原文件。新增七条图文均按用户提供标题录入。
部分既有新闻与通知标题参考已读取的学院首页。简短引言用于演示编排，详情页说明来源；未提供完整新闻正文或通知附件。
讲座时间按海报原文；未标注年份的不补推断年份。界面使用红色和中性色，原始照片与海报保留原色。
行书底纹使用设备可用的 Xingkai SC / STXingkai / STKaiti 等字体，不同设备效果可能不同。
静态演示未接入内容管理后台、报名、账号或全站真实搜索。

## 图片加载优化

将原始大图改为网页用 WebP，首页图文使用 640px 预览，海报列表使用 480px 预览，讲座详情使用 1000px 图片，点击放大才加载完整清晰图。头图优先加载，正文图片延迟加载。
五张海报原文件合计 26,781,627 字节，列表预览合计 433,994 字节；石碑底图由 6,717,365 字节降至 273,720 字节。以上是素材体积对比，不代表实测加载耗时。
原图保存在相邻的 zju-sis-demo-original-assets 文件夹和原有提交中。scripts/optimize_images.py 可重新生成常规图片；image-size-report.json 记录体积。
C 版书法仅有一个共用的本地 WebP 素材，没有外部字体请求。使用内置 imagegen 生成，提示词见 IMAGEGEN-PROMPT.txt；最终资产为 dist/assets/motto-brush.webp。
